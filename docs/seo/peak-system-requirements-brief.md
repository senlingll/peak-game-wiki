# PEAK System Requirements Page Brief

## Decision

- Page type: informational PC compatibility guide.
- Primary keyword: `PEAK system requirements`.
- Recommended slug: `/peak-system-requirements` for English; localized pages use the existing nine-locale route convention.
- Search intent: check official Windows minimum and recommended PC specifications before installing, buying, or upgrading hardware.
- New-page decision: create one page. No existing route answers the CPU, GPU, RAM, DirectX, and storage comparison as a single task. The home page explains PEAK, `/peak-controller-support/` covers input devices, `/room-codes/` covers platforms and multiplayer, and `/peak-game-update` covers patches. The new page does not replace those intents.
- GSC: the 28-day Trends API result checked 2026-11-07 reports 25 clicks, 326 impressions, and average position 30.30. No query met the workflow's position 10-30, at least 50 impressions, and CTR below 5% screen. No GSC query mapped to PEAK system requirements, so this choice comes from Similarweb keyword discovery and an official-source content gap, not an existing ranking URL.

## Content Brief

- Primary keyword: `PEAK system requirements`.
- Candidate variants compared for topic focus: `PEAK PC requirements`, `PEAK minimum requirements`, `PEAK recommended requirements`, `can my PC run PEAK`, and `PEAK download size`.
- Supporting terms: `PEAK game requirements`, `PEAK game requirements for PC`, `PEAK minimum system requirements`, and laptop compatibility wording.
- FAQ terms: can my PC/laptop run PEAK; whether PEAK runs on Mac/Linux; Steam Deck compatibility; required storage versus exact download size; whether minimum specs guarantee smooth performance.
- Do not target: generic `Can I Run It` variants (navigational checker intent), misspellings, Surface-specific claims without a test, Steam Deck compatibility without a verified current rating, or a separate download-size page.
- SEO title: `PEAK System Requirements: Minimum & Recommended PC Specs`.
- H1: `PEAK System Requirements: Minimum & Recommended Specs`.
- Outline: direct answer; official requirements table; meaning of the minimum tier; recommended-versus-minimum comparison; Windows steps for finding PC specs; laptop comparison; storage and DirectX; Windows/Mac/Linux and Deck caveats; what the official table does not establish; FAQ and official sources.
- External source: official PEAK Steam listing and its app-details API; recheck close to installation because requirements and platform availability can change.
- Internal links: new page links to the PEAK overview, controller support, update guide, and price guide. The existing price guide adds a localized related-page link back to this page in all nine locales. Do not add the page to top navigation.
- Acceptance: exact primary phrase in English title, H1, description, first paragraph and a heading; localized equivalents in each locale; raw HTML contains the answer, tables, article body and FAQ; Article and FAQ JSON-LD match visible content; all nine routes have self-canonical and reciprocal hreflang; sitemap includes every route with the build date; three meaningful game-media points render with localized alt and captions.

## Source Facts And Media

Steam app-details API was checked on 2026-11-07 at `https://store.steampowered.com/api/appdetails?appids=3527290&cc=us&l=en`. Minimum: 64-bit Windows 10; Intel Core i5 at 2.5 GHz or equivalent; 8 GB RAM; GTX 1060 or RX 6600 XT; DirectX 12; 16 GB available space. Recommended: 64-bit Windows 11; Intel Core i5 at 3.0 GHz or AMD Ryzen 5 or equivalent; 16 GB RAM; RTX 2060 or RX 7600 XT; DirectX 12; 16 GB available space. Steam did not state FPS, resolution, graphics preset, exact equivalent parts, laptop benchmarks, or a Steam Deck rating. The page reports those absences rather than estimating performance.

This is an informational PEAK fan/wiki page, not a game-download site or download-intent page. The repository explicitly says it does not host a direct game download; the chosen query does not ask for an installer. The related `PEAK download size` variant is answered only to distinguish 16 GB available storage from an unverified download-file size. No version, package, file-size, or download CTA fields require a freshness update, and no download CTA is added.

Three existing official Steam media assets were visually checked and reused: `peak-final-ascent.webp` as the hero, `peak-solo-citadel.webp` in the recommended-spec section, and `peak-solo-route-hazard.webp` in the laptop section. Each shows actual PEAK art/gameplay and has a localized caption stating it is not a performance test. No community screenshot or generated image is used; the existing `peak-map-route.webp` was excluded because it contains a development-build label and FPS counter.
