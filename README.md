# PEAK Game Wiki

PEAK Game Wiki 是一个独立的英文游戏资料站，定位为更新驱动的地图、道具、徽章、联机与补丁信息入口。正式域名为 `https://peak-game.wiki/`。

## Run

```powershell
npm.cmd run dev
```

Open `http://localhost:4173/` for local development.

## Build

```powershell
npm.cmd run build
```

The static publish output is written to `dist/`. Cloudflare Pages serves the production build from the `peak-game-wiki` project.

## Sources

Official game facts and visual media are attributed to the [PEAK Steam page](https://store.steampowered.com/app/3527290/PEAK/) and the [Steam News API](https://api.steampowered.com/ISteamNews/GetNewsForApp/v0002/?appid=3527290&count=20&format=json). This is an independent fan-made wiki prototype and is not affiliated with the developer.
